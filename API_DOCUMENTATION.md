# API Documentation

Base path: `/api/v1`

The current implementation exposes only safe development endpoints. Financial and authenticated routes are planned but intentionally unavailable.

| Method | Endpoint | Auth | Current response |
| --- | --- | --- | --- |
| GET | `/health` | None | Service health, no secrets |
| GET | `/ready` | None | Provider configuration states, never credentials |
| GET | `/api/v1/status` | None | Development API status |
| GET | `/api/v1/catalog/stores/:slug` | None | Public development store DTO |
| GET | `/api/v1/catalog/products` | None | Validated, bounded development catalog response |
| POST | `/api/v1/paystack/webhook` | Paystack signature | Raw-body signature guard; processing remains disabled until persistent idempotency and reconciliation are connected |

## Planned Protected Families

`/auth`, `/vendors`, `/products`, `/checkout`, `/payments`, `/orders`, `/refunds`, `/payouts`, `/ai`, and `/paystack/webhook` require authentication/authorization where appropriate, request validation, endpoint-specific rate limits, structured logs, minimal DTOs, and idempotency for critical mutations.

## Error Shape

```json
{
  "success": false,
  "error": { "code": "VALIDATION_ERROR", "message": "The submitted data is invalid.", "fields": {} },
  "requestId": "request-id"
}
```

No endpoint may return stack traces, provider secrets, private documents, internal database errors, or client-controlled financial decisions.


## Media storage delivery

`POST /api/v1/media/download-url` returns a public R2/custom-domain URL for `public` media when `R2_PUBLIC_BASE_URL` is configured. Otherwise it returns a short-lived signed R2 URL. `private` media always uses authenticated access plus a signed R2 URL.

Image optimization/variants are intentionally not generated by the API yet. The original remains the canonical source object; a Cloudflare delivery/transform layer can be added later without changing the media record or upload lifecycle.
