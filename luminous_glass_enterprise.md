## Brand & Style
The design system embodies a forward-looking, high-trust ecosystem engineered for enterprise AI discovery and vendor orchestration. Blending advanced technical capability with refined sensory depth, the aesthetic balances visionary intelligence with executive-grade poise.

The visual direction marries high-end Glassmorphism with deep atmospheric luminosity:
- **Atmospheric Substratum:** Deep obsidian foundations animated by slow, ambient radial light pools in emerald, deep sapphire, and soft violet/amber, casting controlled luminescence through frosted panels.
- **Precision Specular Glass:** Translucent layered containers featuring calibrated backdrop diffusion, delicate hairline specular borders, and directional top-edge light catchers.
- **Executive Clarity:** Crisp, uncompromising typography and razor-sharp data readouts counteract ethereal glass backgrounds to ensure dense, complex AI telemetry remains effortless to scan.

## Colors
The palette is built on deep cosmic voids, translucent atmospheric overlays, and precision luminous accents:

- **Canvas Foundation (`#090D16`):** An ultra-deep ink sapphire that serves as the infinite baseline, preventing the stark harshness of pure black while absorbing colored glows naturally.
- **Primary Luminescence (`#10B981`):** Precision Emerald. Represents model vitality, active status, high accuracy benchmarks, and primary conversion pathways.
- **Secondary Luminescence (`#3B82F6`):** Deep Sapphire. Delivers structural grounding, navigation focus, enterprise infrastructure metrics, and deep technological stability.
- **Tertiary Accent (`#8B5CF6`):** Soft Violet/Orchid. Applied to AI compute tokens, multimodal workflows, and premium vendor tiers.
- **Warm Accent (`#F59E0B`):** Soft Amber. Reserved for latency warnings, critical compute limits, and highlighted enterprise audits.
- **Specular Glass Structure:** Built using controlled opacities of white (`rgba(255, 255, 255, 0.03)` up to `0.14`) for fills, edged by hairline light accents (`rgba(255, 255, 255, 0.12)` to `0.28`).
- **Typography & Content:** High-contrast ivory (`#F8FAFC`) and cool slate neutrals (`#94A3B8`, `#64748B`) guarantee crystal-clear legibility over shifting background hues.

## Typography
Typography is tuned for extreme crispness over translucent and luminous textures:

- **Primary Typeface (Plus Jakarta Sans):** Its geometric foundation, open counters, and modern curves provide warmth without sacrificing technical precision. Headings utilize tight negative letter spacing to project authority and sleek density.
- **Monospace Companion (JetBrains Mono):** Introduced for vendor model hashes, API latency rates, token pricing tables, and runtime telemetry. It reinforces technical authenticity.
- **High-Contrast Readability Rule:** Text placed directly on semi-translucent glass panels strictly avoids low-contrast grays; body text defaults to neutral-100 or neutral-200 with calibrated opacity thresholds to prevent color washout from shifting underlying mesh glows.

## Layout & Spacing
The layout follows a 12-column responsive fluid grid operating on an 8px base rhythm (with 4px sub-intervals for fine UI elements).

- **Spatial Rhythm:**
  - **Desktop (>= 1280px):** 12 columns, `1.5rem` (24px) gutters, `3rem` (48px) safe margins. Max layout container width clamped at `1440px`.
  - **Tablet (768px - 1279px):** 8 columns, `1.5rem` (24px) gutters, `2rem` (32px) margins. Side panels convert to overlaid glass drawers.
  - **Mobile (< 768px):** 4 columns, `1rem` (16px) gutters, `1rem` (16px) margins. Cards and metrics stack vertically; navigation anchors to a frosted bottom dock.
- **Internal Frosted Container Rules:** Translucent glass cards require generous internal breathing room (`space-lg` to `space-xl`) to preserve the frosted visual depth without crowding data points.

## Elevation & Depth
Elevation is generated through optical diffusion, backdrop filtration, and layered specular light rather than traditional opaque drop shadows:

- **Level 0 (Canvas Base):** Ink sapphire (`#090D16`) populated with static or slowly oscillating soft radial gradients (200px–500px blur radius, 15%–25% opacity) in emerald, sapphire, and violet.
- **Level 1 (Subsurface Glass / Inactive Panels):**
  - Background: `rgba(255, 255, 255, 0.03)`
  - Backdrop Blur: `12px`
  - Border: Hairline 1px `rgba(255, 255, 255, 0.08)`
  - Shadow: None or faint ambient diffusion `0 4px 20px rgba(0, 0, 0, 0.25)`
- **Level 2 (Interactive Glass / Vendor Cards & Modules):**
  - Background: Linear gradient from `rgba(255, 255, 255, 0.07)` at top to `rgba(255, 255, 255, 0.02)` at bottom.
  - Backdrop Blur: `20px`
  - Border: 1px `rgba(255, 255, 255, 0.18)` with a high-light specular top edge (`rgba(255, 255, 255, 0.32)`).
  - Shadow: `0 12px 32px -4px rgba(0, 0, 0, 0.35)`, plus an inner specular bevel `inset 0 1px 0 rgba(255, 255, 255, 0.2)`.
- **Level 3 (Elevated Overlays / Modals, Popovers, Floating Bars):**
  - Background: `rgba(15, 23, 42, 0.65)` layered with `rgba(255, 255, 255, 0.06)`
  - Backdrop Blur: `32px`
  - Border: 1px `rgba(255, 255, 255, 0.28)`
  - Shadow: `0 24px 64px -12px rgba(0, 0, 0, 0.6)`, paired with a soft radial bloom matching the primary brand accent.

## Shapes
Geometry is smooth and structural, balancing architectural discipline with organic fluid refraction:

- **Standard Elements (Buttons, Inputs, Badges):** `0.5rem` (8px) to `0.75rem` (12px) curvature for compact touchpoints.
- **Cards & Data Surfaces:** `1rem` (16px) corner radius, allowing continuous, undisturbed specular borders to frame content.
- **Large Hero Panels & Modals:** `1.5rem` (24px) corner radius.
- **Status Pills & Telemetry Badges:** Fully rounded capsule/pill architecture to contrast cleanly against geometric data grids.

## Components

### Buttons
- **Primary Action:** Solid emerald core (`#10B981`) with soft glowing drop shadow (`0 0 24px rgba(16, 185, 129, 0.35)`), crisp dark-slate text (`#022C22`), and subtle top specular reflection line.
- **Glass Secondary:** Translucent surface (`rgba(255, 255, 255, 0.06)`), 1px border (`rgba(255, 255, 255, 0.2)`), backdrop blur `12px`. On hover, background shifts to `rgba(255, 255, 255, 0.12)` with border blooming to primary emerald or sapphire.
- **Ghost / Tertiary:** Transparent fill, `rgba(255, 255, 255, 0.7)` typography, animating to crisp white on hover with micro-highlight background.

### Vendor Cards
- Layered Level 2 glass container with 1px continuous specular border.
- Integrated header featuring vendor avatar, glowing status dot (emerald for active/verified, amber for degraded), and model class badge.
- Interactive hover: smooth vertical translation (`-2px`), specular border opacity rises to `0.35`, and a subtle emerald/sapphire underglow activates beneath the card.

### Badges & Chips
- Capsule-shaped (`rounded-full`), `rgba(255, 255, 255, 0.05)` base fill with backdrop blur.
- Tinted specular borders matched to category (e.g., emerald for "LLM", sapphire for "Embedding", violet for "Autonomous Agent").
- Micro pulse indicators (`w-1.5 h-1.5` rounded light nodes) embedded in telemetry chips.

### Form Inputs & Search Fields
- Inset glass styling: `rgba(0, 0, 0, 0.25)` fill with 1px `rgba(255, 255, 255, 0.12)` border.
- Focus state: Border illuminates to emerald (`#10B981`), backed by an exterior ambient glow ring (`0 0 0 3px rgba(16, 185, 129, 0.2)`). JetBrains Mono used for parameters, tokens, and query strings.

### Telemetry Lists & Data Tables
- Alternating row glass fills with ultra-subtle dividers (`rgba(255, 255, 255, 0.06)`).
- Sticky glass headers utilizing `backdrop-blur-md` for seamless scrolling over dense benchmark lists.

### Specialty: AI Status Hub & Model Metrics
- Live metric cards featuring integrated SVG mini sparklines in emerald or sapphire, sitting over tinted glass depth gradients with glowing origin vertices.
